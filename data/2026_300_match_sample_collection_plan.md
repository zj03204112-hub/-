# 2026年以来300场独立比赛样本：采集与冻结规范

状态：采集规范已记录；300场数据尚未完成采集/核验。不得将本文件视为已完成样本。

## 目标范围
- 比赛日期：2026-01-01 至采集运行日（当前目标截至 2026-10-12）。
- 联赛：英超、西甲、德甲、意甲、法甲、韩国 K League 1、日本 J1 League。
- 只纳入已完赛的男子一线队常规联赛比赛。
- 排除：国内杯赛、超级杯、友谊赛、欧战/洲际赛事、青年/女子赛事、延期未赛/腰斩/无最终比分比赛。
- 目标：300 场唯一比赛；不能为了凑满 300 场而复制、替换或放宽排除条件。若合格数据不足，报告实际数量与缺口。

## 采样原则
1. 优先从 2026 年以来符合范围的比赛建立完整候选池，再去重和核验，之后才抽取 300 场。
2. 分层覆盖七个联赛，并覆盖不同月份、主/客胜/平局结果；不得根据模型是否预测正确筛选样本。
3. 若做模型开发/校准，冻结前先固定随机种子与抽样规则；建议 180 训练、60 校准、60 盲测。盲测集在方案锁定前不得用于调参。
4. 若样本用于纯回测而非建模，仍需保留完整候选池、抽样种子、入选/排除原因，保证可复现。

## 每场最低字段
- sample_id（1..300，唯一）
- match_date（ISO 日期，明确当地日期与时区）
- league、season、round
- home_team、away_team
- home_goals、away_goals、result_90m（H/D/A）
- source_primary、source_secondary、source_match_url
- provider_match_id（如来源提供）、db_match_id（完成唯一映射后填写）
- verification_status（verified / needs_review / unresolved）
- included_reason、notes

## 数据质量门槛
- 300/300 唯一比赛键；键优先为联赛 + 当地比赛日期 + 规范化主队 + 规范化客队，最终比分用于核对而非唯一身份键。
- 0 个未解决或歧义映射；不确定的比赛不得混入冻结样本。
- 两个独立来源核对比赛身份和最终比分；若只有一个来源，标记待复核，不直接计入最终冻结集。
- 不把亚洲让球盘当作竞彩官方让球数据；官方竞彩盘口只有在找到可核实的官方记录及对应时间时才填写，否则明确留空。
- 预测特征必须是赛前可得信息，避免使用赛后数据泄漏；预测时间基准遵循既定 T-6 至 T-12 小时规则（如有可靠历史快照）。
- 原始来源快照、清洗前候选池、排除清单、冻结 CSV、SHA256 和汇总 JSON 分开保存；冻结后只追加勘误记录，不静默覆盖。

## 完成定义
只有在冻结 CSV 实际包含 300 行且通过上述唯一性、比分核验和映射检查后，才可报告“300 场样本完成”。采集脚本提交、工作流配置存在或网页搜索到部分比赛均不等于完成。
