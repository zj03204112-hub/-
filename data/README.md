# 数据库说明

## 当前目标

持续保存：
1. 2026/27 当前赛季已完成联赛赛果；
2. 本模型在比赛开始前的让球判断；
3. 最终让球结果；
4. 命中/错误；
5. 错误原因与规则修正。

## 当前优先联赛

英超、西甲、德甲、意甲、法甲、韩国K League 1、日本J1 League。

## 数据原则

只纳入联赛比赛。杯赛、友谊赛、欧战单独排除。

## 时间口径

“当前赛季”与“2026日历年数据库”分开保存。欧洲五大联赛当前赛季为2026/27；K League为2026赛季；J1当前数据源标示为2026/27。

## 模型判断

prediction 文件保存的是当时模型判断，不代表事实结果。结果核实后再进入 review。

## 复盘

先比较：
- 胜负方向
- 净胜球分布
- 让球胜平负
- 比分
- 半全场
- xG/xGA偏差
- 阵容/伤停
- 战术
- 赛程/战意
- 下一场对手
- 盘口变化

然后更新模型规则。
