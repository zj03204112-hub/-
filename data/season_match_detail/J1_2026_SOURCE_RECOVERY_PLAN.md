# J1 2026/27 数据完整性恢复方案（来源核验版）

更新时间：2026-11-01

## 已确认的阻塞
- API-Football 免费套餐不支持 2026 赛季；现有自动采集工作流因此失败，不能把 artifact 上传成功当作数据采集成功。
- 官方 J.League Data Site 和 J.LEAGUE 官方比赛页可追溯赛果、首发阵容、替补及换人事件；官方比赛页示例含换人分钟。官方公开页目前未确认提供 xG。
- SportMonks 官方 J1 API 页面宣称提供稳定球员/球队 ID、首发、替补、换人事件、比赛统计及 xG；其公开定价为 Starter 起价 €29/月，xG add-on 另起价 €29/月。必须先确认 2026 J1 的实际字段覆盖和许可，再将其作为 xG 供应源。

## 字段来源策略
| 字段 | 主来源 | 交叉核验 | 禁止行为 |
|---|---|---|---|
| 比赛日期、主客队、比分 | J.League Data Site / 官方 J.LEAGUE match report | 已有 126 场映射表 | 不用未核实的第三方比分覆盖官方结果 |
| 首发 11 人、替补名单 | 官方比赛报告 lineup | SportMonks / 其他供应商（若已配置） | 不把替补名单当作实际出场 |
| 换人事件与分钟 | 官方比赛报告 match progress | SportMonks events | 不从球员是否在替补名单推断已出场 |
| 球员 ID | 官方球员资料链接或供应商稳定 player ID；保存来源 ID 与原始 URL | 按比赛、球队、姓名交叉匹配 | 不用姓名生成伪 ID；无法匹配时保留空并列为问题 |
| 实际出场分钟 | 官方换人事件推导并标记算法，或供应商 player minutes | 逐场核对红牌、伤停补时、加时等边界 | 不把所有首发都直接记 90 分钟 |
| xG / xGA | 需经验证的逐场 xG 供应商（优先评估 SportMonks xG add-on） | xGA 必须等于对手同场 xG，并保留来源 | 不以进球数、射门数或模型估值伪装成供应商 xG |

## 硬性验收门
- 126 场已有比赛映射必须按稳定内部 match ID 一对一对应；日期、主客队、比分与官方记录全部一致。
- 每场已完赛比赛双方首发必须恰好 11 人；姓名与球员 ID 均无重复、无跨队错配。
- 替补名单、换人事件、入场/离场球员与分钟分别存储；实际出场只能由实际事件/出场统计确认。
- xG/xGA 逐场保留原始值、供应商、供应商事件 ID、抓取时间及原始响应；xGA 与对手 xG 不一致即失败。
- 报告必须输出总场数、已完赛场数、每项覆盖率、缺失/重复/错配清单和来源 URL。
- 未达到字段覆盖率 100% 的数据层不得标记为“完整”或“验收通过”；缺失值必须为空并说明原因，禁止插补成事实数据。

## 执行边界
当前分支尚无已生成并通过审计的标准化球员明细 CSV。来源方案记录不代表数据已采集。完成 xG 层需要已验证可访问的供应商凭证与 J1 2026 覆盖；凭证应只放在 GitHub Actions Secrets，不得提交到仓库或聊天中。

## xG/xGA 免费来源核验更新（2026-11-02）

- 已发现可公开浏览的 FootyStats J1 xG 页面：`https://footystats.org/japan/j1-league/xg`。页面提供逐场近期结果的主/客 xG，但其说明采用自有算法（射门准确度、射门频率、进攻威胁、控球及进攻压迫等），因此必须标为第三方 provider-specific xG，不可标作 J.League 官方 xG。
- 当前从公开可见的近期结果中，按主客队、比分与既有内部比赛映射联合核对后，写入 11 场 xG；同场 xGA 机械定义为对手 xG。其余 115 场为空值，不做进球数或模型插补。
- GitHub Actions 直接请求该页面返回 HTTP 403。采集脚本已调整为保留先前有来源记录的数值，并把源不可访问状态写入审计；这不代表自动更新已成功。
- 该公开页面本轮显示的近期结果中，另有 3 场日期为 2026-11-01（长崎–东京V、千叶–福冈、横滨FM–川崎F），超出当前 126 场映射表截止日期 2026-10-31，因此未强行映射到旧比赛 ID。
- xG 文件：`j1_2026_match_xg_free.csv`；审计：`j1_2026_match_xg_free_audit.json`。
- 当前覆盖率为 11/126（8.73%）。达到 100% 前，xG/xGA 层仍不得标记为完整。下一步继续核验是否存在可免费浏览、可逐场追溯且不依赖付费 API 的历史来源。
