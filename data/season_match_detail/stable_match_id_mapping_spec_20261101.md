# 稳定比赛 ID 映射层（初始登记）

生成日期：2026-11-01

## 目的
分开保存内部稳定 ID、来源行、供应商赛事 ID 和官方比赛页 URL。内部 ID 由联赛、赛季、日期、主客队规范化字符串组成；来源队名和比分原样保留，后续别名修正不得覆盖原始字段。

## 文件
- `j1_2026_match_id_mapping.csv`：由当前 J1 2026 CSV 生成的候选登记行。
- `kleague1_2026_match_id_mapping.csv`：由当前 K League 1 2026 CSV 生成的候选登记行。

## 状态约束
- 当前登记文件仅为映射工作队列，不代表官方 ID 映射或逐场复核已完成。
- `provider_event_id`、`official_match_url` 留空直到取得可验证来源，不猜测、不合成供应商 ID。
- `official_result_check_status=pending`；日期、主客队、比分四项必须逐场与官方比赛页面对照后才能改为 `verified`。
- 首发与实际出场记录分开审核；不能把 XI 名单当作替补/实际出场完整记录。
- 队名别名统一放入独立 alias mapping，不修改原始来源字段。
- 赛果数据层只接收已完赛且比分经可靠来源确认的记录；空比分不得补猜。

## 当前来源限制
J1 2026 当前文件为 125 行，官方逐场复核仍未完成。K League 1 当前文件为 80 行且只覆盖到 2026-05-12，不代表完整赛季。两个映射文件均是待核验队列。
