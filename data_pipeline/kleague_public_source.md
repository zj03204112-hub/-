# Public K League 1 source configuration

K League 1 is included again in the project.

Primary public source for completed fixtures/results:
https://portal.kleague.com/view/schedule/list.do
https://www.kleague.com/schedule.do

The official K League Open API is also documented at:
https://api.kleague.com/docs/index.jsp
It requires an authKey, so it is optional for the baseline result collector.

Secondary public dataset:
https://footystats.org/south-korea/k-league-1/datasets

Scope remains 2026-01-01 through 2026-09-20 and league matches only.
