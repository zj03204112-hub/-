## 1. 让球映射与原始字段一致性

### 规则固定

竞彩让球结果必须独立于90分钟胜平负计算，并且只用第一比分：
`adjusted_home = first_score_home + official_home_handicap`
比较 `adjusted_home` 与第一比分的客队进球：
- 大于：让胜
- 等于：让平
- 小于：让负

第二比分不得参与让球结果。

### 恢复样本审计

- 004—028共25条恢复预测中，按“第一比分+恢复档案所列盘口”机械核算，发现1条预测标签冲突：028。
- 028：第一比分2–1、主队-1 → 2−1−1=0，机械结果为让平；原恢复标签为让胜。
- 其余24条与机械映射相符。

### 官方盘口真实性状态

当前恢复文件中的让球值来自历史对话恢复档案，不是当时官方竞彩出票页面/接口原始响应。公开赛果页可以交叉核对赛事和终场比分，但不能证明每场的赛前官方让球值与16:38快照完全一致。因此本阶段的结论应分成两项：
1. **标签机械一致性：** 已审计，028不一致。
2. **官方盘口来源一致性：** 未完成。25场均需与官方竞彩历史页面、原始接口响应或出票快照逐条核对；不能用其他公司的亚洲盘代替官方竞彩盘口。盘口无法独立确认的行必须标记为“官方盘口未验证”，不得用于最终让球准确率验收。

## 2. 比分分布：独立冻结500场诊断

数据文件：`model_validation/500_match_V4_frozen_predictions.csv`。以下仅为既有冻结样本的描述性核对，不用10月11日25场反向调参。

### 90分钟概率与分类问题

| 指标 | 冻结500场现有输出 |
|---|---:|
| 实际主胜 / 平 / 客胜 | 241 / 116 / 143 |
| 实际平局比例 | 23.2% |
| 最终分类预测平局 | 0 |
| 平局召回率 | 0% |
| 总体准确率 | 48.0% |
| Brier | 0.61883 |
| Log Loss | 1.03237 |

概率文件中存在非零的 `p_draw`，但现有最终分类仍然没有一场选平。这更像是“概率到分类的决策/标签路径”有问题，而不能仅凭这个现象判定 Poisson 的 λ 一定有错。

### 0、1、2、3+ 净胜球分布

下表用实际比分绝对净胜球与第一预测比分的绝对净胜球分箱比较：

| 绝对净胜球 | 第一比分预测 | 实际 |
|---|---:|---:|
| 0 | 374 | 116 |
| 1 | 124 | 204 |
| 2 | 2 | 116 |
| 3+ | 0 | 64 |

这表示第一预测比分过度集中于平局比分，且几乎没有净胜2球及以上的比分；注意这是“第一比分”分布，不是完整 λ 概率矩阵的净胜球分布。必须再从模型输出重建每场比分概率矩阵，计算 `P(goal_diff=0)`、`P(|goal_diff|=1)`、`P(|goal_diff|=2)`、`P(|goal_diff|>=3)`，再与实际分布比较，才能判断概率质量是否分布错误，还是仅仅第一比分排序错误。

### 总进球分箱

| 总进球 | 第一比分预测 | 实际 |
|---|---:|---:|
| 0–2 | 374 | 230 |
| 3 | 119 | 120 |
| 4+ | 7 | 150 |

第一比分明显低估4+总进球场次。该结果支持进一步检查 λ 估计、尾部截断/分布和 score1 排序，但不能单凭精确比分命中率决定调高 λ。

## 3. 平局概率校准：350训练 / 150严格时间留出

使用冻结500场按原顺序划分：前350场用于选择平局概率乘数，最后150场只用于评估。乘数仅乘在 `p_draw` 上，随后对三类概率重新归一化。该实验仅为诊断，不改生产模型。

### 方案A：训练集按多分类 Log Loss 选择乘数

训练集选出的乘数为 **0.975**，并未支持上调平局概率。

| 指标 | 留出集基线 | 乘数0.975 |
|---|---:|---:|
| 样本数 | 150 | 150 |
| 胜平负准确率 | 38.67% | 38.67% |
| 平局召回率 | 0% | 0% |
| Brier | 0.65608 | 0.65661 |
| Log Loss | 1.08378 | 1.08458 |

结论：留出集Brier和Log Loss均略微变差，平局召回率没有改善。**不接受此校准方案。**

### 方案B：用训练集偏重平局召回的诊断压力测试

训练集按平局F1选择乘数时，乘数约2.50；留出集结果：

| 指标 | 留出集基线 | 乘数2.50 |
|---|---:|---:|
| 胜平负准确率 | 38.67% | 29.33% |
| 平局召回率 | 0% | 84.62% |
| 平局精确率 | 无预测平局 | 25.38% |
| Brier | 0.65608 | 0.69409 |
| Log Loss | 1.08378 | 1.14243 |

结论：平局召回率虽然提升，但误报大量增加，整体准确率、Brier和Log Loss都明显恶化。**不接受此方案，也不能把“提高平局召回率”单独当成优化成功。**

## 4. 下一步代码级排查顺序

1. **让球数据门禁：** 新增/运行机械一致性断言；盘口原值必须带来源、抓取时间和官方来源标识。第一比分+官方盘口算出的标签与存储标签不一致时，阻止归档/回测。
2. **净胜球分布重建：** 从冻结样本的每场赛前 `lambda_home`、`lambda_away` 和完整比分矩阵导出0/1/2/3+净胜球概率；若现有CSV没有这些字段，则重新运行只读预测生成过程并保存中间概率，不改参数。
3. **分类路径定位：** 查明为何 `p_draw` 非零但500场最终分类预测平局为0。检查 argmax、类标签映射、阈值、概率列顺序与输出后处理。
4. **独立平局实验：** 只有在分类路径修正并通过单元测试后，再使用历史训练集拟合概率校准，保留完全未参与拟合的冻结留出集。接受条件：Brier与Log Loss不恶化，平局召回率改善且整体准确率没有不可接受的下滑。
5. **生产隔离：** 全部只在 `feature/v5.2-classification-data-audit` 实验分支进行。V5.1、原始预测、冻结样本均不覆盖。
