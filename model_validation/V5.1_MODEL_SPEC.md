# V5.1 模型规格

## 版本定位
V5.1 为 V5-SCORE 的独立验证版本，不覆盖、不修改 V5-SCORE v1.0。

## 固定验证基准
使用仓库中已保存的欧国联 50 场 V5 重建版样本：`欧国联/2026-09-29/V5-Score_50场_已完赛.csv`。

## 当前验证规则
- 使用 V5 预测比分1、比分2作为候选比分。
- 胜负方向按90分钟实际比分判断，不使用让球。
- 比分1作为主比分参考。
- 比分2作为第二独立比分参考。
- 不把本次50场回测结果直接当作独立前瞻命中率。

## 50场回测基准
- 比分1精确命中：33/50 = 66.0%
- 比分2精确命中：4/50 = 8.0%
- 比分1胜平负方向命中：48/50 = 96.0%
- 比分2胜平负方向命中：31/50 = 62.0%
- 两个候选比分至少一个精确命中：37/50 = 74.0%
- 两个候选比分至少一个胜平负方向命中：50/50 = 100%

## 版本边界
V5.1 仅记录当前 V5 结果的固定化与回测基准；后续若调整权重、输入、比分生成、概率映射、让球映射或置信度计算，应创建 V5.2 或更高版本，不覆盖本文件。
