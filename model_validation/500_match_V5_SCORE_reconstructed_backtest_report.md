> 当前仓库只保存了V5-SCORE v1.0的结构、变量、流程和规则，历史V5的完整代码、精确训练权重和全部参数矩阵没有完整恢复。因此本次不能把结果称为“原始V5盲测”。为避免伪造参数，本次采用冻结的透明重建方案：历史赛果 → 时间衰减近期攻防率 → 主客场基准 → 对手攻防归一化 → Poisson比分分布 → Dixon-Coles低比分修正。xG、球员影响力、真实伤停、首发、战术、天气、裁判、赛程战意、新闻及专业评论员数据在500场样本中不完整，因此这些模块本次按“未知/中性”处理，**不补造数据**。

## 七、本次回测的关键限制

1. **没有恢复原始V5精确权重。**
2. 本次V5是冻结规则下的透明重建，不是原始V5代码盲测。
3. 500场样本没有完整保存赛前6–12小时的全部V5输入快照。
4. 因此不能判断“伤停、首发、球员状态、战术、赛程战意、天气、裁判、新闻”等模块是否真正贡献了增益。
5. 本次没有根据500场结果反向调参，因此没有把测试集命中率用于参数拟合。
6. V3/V4本身也是此前已经完成的基础结构重放，输入缺失问题同样存在。

## 八、当前版本结论

**本次可以正式归档为：V5-SCORE v1.0重建版 / 500场独立样本回测。**

但不能写成“原始V5已经恢复并通过500场正式盲测”。

本次得到的三个基线应固定保存：

- V3：500场方向 **46.40%**
- V4：500场方向 **45.20%**
- V5-SCORE v1.0重建：500场方向 **51.00%**

以及时间留出：

- V3：200场 **47.00%**
- V4：200场 **46.50%**
- V5重建：200场 **47.00%**

**下一步不建议立即修改V5参数。** 正确顺序应是：先把V5重建版作为v1.0固定基线，再做“输入模块消融”，优先补齐真实的赛前6–12小时首发、伤停、球员状态、赛程/战意和xG数据，然后重新在独立样本上验证增量。
