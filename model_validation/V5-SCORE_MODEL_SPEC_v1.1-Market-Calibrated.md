# V5-SCORE v1.1-Market-Calibrated 实验规范

## 定位
- 基线：V5-SCORE v1.0（冻结，不修改）
- 样本：冻结500场 model_validation/500_match_base_batch01.csv
- 目的：检验赛前市场信息作为辅助校准后，比分/总进球/90分钟概率质量是否改善。
- 本版本为实验版，不替换v1.0生产基线。

## 市场输入
优先使用 Football-Data 非 C 列市场数据：
- 1X2：开盘后/早期欧赔
- O/U：2.5球等可用总进球盘口及水位
- AH：Asian Handicap 开盘/早期盘口及水位
- 明确排除 C 列收盘赔率，避免把收盘信息直接当作赛前输入。
- K League 1 当前无同源完整市场字段时标记缺失，不补造。

Football-Data公开说明其自2019/20起保存两组赔率：第一组为市场开盘后采样，第二组为收盘赔率（C列）。本实验只取第一组。该数据时间点不保证严格等于每场开赛前6–12小时，因此结果必须标记为“开盘后/早期市场校准实验”，不能宣称为严格T-12盲测。

## 校准方式
1. 先按v1.0原有lambda生成8×8 Dixon-Coles矩阵。
2. 欧赔：归一化隐含概率作为小权重的H/D/A校准信号。
3. 亚盘：盘口方向+两侧水位作为强弱差辅助信号。
4. O/U：盘口与Over/Under隐含概率共同调整lambda总和，使总进球分布向市场信号有限靠拢。
5. 市场校准权重固定为小幅度实验参数，不根据测试500场结果反向调参。
6. 重新生成完整8×8矩阵，再提取比分1、比分2、90分钟和总进球预测。
7. 不允许先决定H/D/A或让球结果再倒推比分。

## 评价
同时比较：
- 总进球精确预测准确率、总进球MAE
- 比分1命中率
- 比分2命中率
- 90分钟胜平负准确率
- 2.5球方向准确率；若2.75市场字段完整，再单独统计2.75
- Brier
- Log Loss
- 8×8矩阵L1变化量及lambda变化

## 独立性
- v1.0预测链保持不变。
- v1.1市场输入只作为新增校准层。
- 实际赛果只用于评价。
- 不使用收盘C列。
- 不把缺失市场数据补成默认赔率。
- 若市场覆盖不足，则输出覆盖率并停止“500场完整市场实验”结论，不伪造完整样本。

## 版本规则
任何正式采用v1.1参数、市场权重或新的数据截面，都必须保留本实验记录，并升级后续版本号；v1.0历史预测不得覆盖。
