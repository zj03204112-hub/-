# 雷速体育完赛赛果核对与复盘规则

## 默认触发
当用户要求“核对赛果”“复盘比赛”“复盘今天预测”或类似任务时，默认自动搜寻雷速体育已经完赛的赛果；无需再次询问数据源。用户提供雷速体育截图时，截图可作为本轮赛果核对依据，并与可访问的雷速公开赛果交叉验证。

## 赛果获取与状态筛选
1. 优先使用雷速体育比分/赛果页，筛选状态明确为“完”的比赛并读取终场比分。
2. 进行中、未开赛、延期、中止、腰斩、取消及终场比分无法可靠确认的比赛，不计入命中率；单独列出状态和原因。
3. 不得把实时比分、半场比分或未经确认的页面片段当作终场比分。
4. 按比赛日期、联赛、主客队匹配赛前预测；发现队名别名、比赛日期或赛事编号有歧义时，先核实，不强行匹配。
5. 记录赛果来源与核验时间。若雷速数据不可访问或无法确认，应明确说明并请求可用截图/来源，不得声称已成功抓取。

## 预测核验字段
逐场保留原始赛前预测，不得事后修改：
- 原始预测版本、预测时间和比赛标识（可获得时）
- 90分钟胜/平/负预测与实际结果
- 第一比分、第二比分分别核验及“前两比分至少命中一个”
- 半全场预测与实际半全场
- 官方竞彩让球数、预测让球胜平负、实际让球胜平负
- 核验状态、来源、备注及错误类型

## 结算规则
1. 90分钟胜平负与竞彩让球胜平负必须独立核算。
2. 竞彩让球实际结果必须依据官方主队让球数和实际终场比分机械计算；若官方让球数未核实，标注“待核实”，不猜盘口。
3. 让球结果只根据第一比分对应的赛前预测来核对；第二比分不得参与让球结算。
4. 取消、中止或无有效终场赛果的比赛排除出命中率分母。
5. 同时报告分子、分母和命中率；区分“本轮对话预测清单统计”与“模型数据库/指定模型版本正式回测”。没有可追溯的原始预测快照时，不得冒称为 V5.1/V5.2 正式回测。

## 汇总与复盘
先列完赛、未完赛/状态异常和未匹配比赛，再分别汇总胜平负、第一比分、第二比分、前两比分覆盖、半全场和让球准确率。分析错误时区分强弱判断、平局识别、进球分布/净胜球、阵容/伤停与盘口映射；小样本只能作为诊断线索，不可据此宣称模型提升或直接覆盖生产参数。

## 数据归档
保留原始预测与赛后结果的对应关系；新增复盘记录，不覆盖原预测。若仓库数据库/工作流不可访问或写入未确认，必须如实说明，不能声称已经保存。任何模型版本对比必须使用相同、可追溯的独立样本，并保留模型版本与预测冻结时间。
