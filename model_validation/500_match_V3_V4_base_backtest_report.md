# 500场独立样本 V3/V4 基础模型回测报告

- 样本文件：model_validation/500_match_base_batch01.csv
- 样本数：500
- 去重：500/500，重复键（日期+联赛+主客队）=0
- 本报告用途：先验证原始 V3/V4，再决定是否调整模块；本报告不使用测试结果反向修改模型。
- 回测方式：按比赛日期滚动，只使用该场比赛日期之前已经进入500场样本的比赛；另给出最后40%（200场）的时间切分留出结果。
- 重要限制：500场CSV主要保存赛果，缺少完整的赛前 lineup_projection / schedule_intent / 盘口等输入。因此这里是“V3/V4基础结构重放”，阵容与赛程战意输入在缺失时按中性处理，不等同于完整生产版V3/V4的全部T-12h输入。不能把本报告冒充成完整生产数据库回放。

## 四、置信度检查

V3：
- 全500场平均置信度49.62%，实际命中46.40%，差值+3.22个百分点。
- 最后200场平均置信度49.09%，实际命中47.00%，差值+2.09个百分点。

V4：
- 全500场平均置信度46.61%，实际命中45.20%，差值+1.41个百分点。
- 最后200场平均置信度46.39%，实际命中46.50%，差值-0.11个百分点。

因此当前500场基础重放没有支持“90%置信度≈90%命中”这种解释；置信度必须继续做概率校准。

## 五、当前结论：只做诊断，不改参数

1. **先不改V3/V4核心参数。**
2. V3和V4都没有达到可以直接宣称高准确率的水平。
3. V4在本次基础重放中概率指标（Brier、LogLoss）与净胜球MAE表现与V3不同，但90分钟方向命中率并没有同步提高。
4. V4的比分Top-1在本500场重放中为13.8%，最后200场为12.5%；不能仅凭这一项决定模型升级。
5. V3的方向命中率在最后200场为47.0%，V4为46.5%，两者差距很小。
6. 500场目前缺少完整T-12h首发、伤停、赛程战意、盘口变化等字段，因此**不能据此判断这些模块本身有效或无效**。
7. 下一阶段应该先做“输入完整度审计 + 模块消融”，而不是直接改参数。

## 六、下一阶段固定验证顺序

A. 先锁定当前V3/V4基线，不改参数。

B. 对500场逐场检查可用输入：
- 近期比赛
- 对手强度
- 首发
- 伤停
- 赛程间隔
- 下一场对手/战意
- 盘口
- xG/射门
- 球员状态

C. 再做消融：
- V3基础
- V3 + 赛程/战意
- V3 + 首发/伤停
- V3 + 球员状态
- V4基础
- V4 + 上述模块

D. 所有模块只能使用比赛发生前的数据；不能使用赛果倒灌。

E. 最终只在时间留出样本上判断是否值得升级。
