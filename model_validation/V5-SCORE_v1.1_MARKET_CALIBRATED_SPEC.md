# V5-SCORE v1.1-Market-Calibrated（实验版）

状态：EXPERIMENT_ONLY，不替换 V5-SCORE v1.0。

## 目标
在完全相同的冻结500场样本、T-12h信息截止和V5-SCORE v1.0基础 λ/8×8 矩阵上，增加独立市场校准层，测试：
1. 总进球预测
2. 比分1命中
3. 比分2命中
4. 90分钟 H/D/A
5. 让球 H/D/A
6. O/U 2.5、2.75 等方向
7. Brier / LogLoss
8. 校准前后8×8矩阵变化

## 市场输入
- 亚盘：盘口、主客水位
- 欧赔：主/平/客水位
- 大小球：盘口、Over/Under水位
- 所有市场输入必须满足 captured_at <= kickoff - 12h。
- 市场字段缺失时不补造、不回填临场数据；该场只进入覆盖率审计，不进入“完整市场500场”主实验。

## 校准原则
- v1.0 原始 λ、原始8×8矩阵保留为 baseline。
- 市场层只能对 λ_home / λ_away 做有限幅度修正，再重新生成完整8×8矩阵。
- 不允许从市场直接指定 H/D/A 或精确比分。
- 不允许使用赛果倒灌拟合市场参数。
- 参数只能在时间顺序前60%训练集拟合，后40%作为完全独立测试集。
- 市场修正系数设置上限，避免模型退化成赔率复制器。
- v1.1 的比分1/比分2均从修正后的8×8矩阵独立提取。

## 让球
预测让球由预测比分/概率矩阵叠加赛前实际记录的盘口计算；赛后命中使用实际比分+同一赛前盘口。
若官方竞彩盘口不可核验，该项记为 NA，不用其他亚洲盘替代竞彩盘口。

## O/U
2.5、2.75 等盘口按对应结算规则计算；若市场没有该盘口，不强行转换成另一个盘口。

## 独立对照
必须同时保存：
- V5-SCORE v1.0 baseline
- V5-SCORE v1.1-Market-Calibrated
- market coverage / missingness
- train/test split
- calibration parameters
- per-match matrix delta
- aggregate metrics

只有独立测试集在目标指标上形成稳定改善，才考虑后续正式版本；本实验结果不得自动升级生产模型。
