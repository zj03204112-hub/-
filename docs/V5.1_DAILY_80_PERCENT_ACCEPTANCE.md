# V5.1/V5.x 胜平负准确率目标与验收门槛

生效日期：2026-10-10

## 用户目标
- 每日优先覆盖至少 6 场；通常输出 6–8 场比赛的 90 分钟胜平负预测。
- 目标：所选场次的 90 分钟胜平负命中率达到 80% 以上。
- 此目标是模型优化目标，不是可以预先保证的每日结果。单日 6–8 场样本太小，结果会有很大波动；不得为达标而挑选性删除失误或事后改预测。

## 预测和统计规则
1. 每场在开赛前 6–12 小时生成预测快照，记录时间、版本、策略编号、主/平/客概率、首选结果、两个比分和所有可用输入。
2. 预测一经冻结不得覆盖。赛后新增的信息不得回填为赛前特征。
3. 原始赛前快照缺失的场次标记“缺失预测”或“回顾性重建”，不进入正式命中率。
4. 90 分钟胜平负独立统计；竞彩让球胜平负独立核算，且只由第一比分和已核实赛前竞彩让球数机械映射。第二比分不参与让球计算。
5. 同时报告每日命中率、滚动 30/100 场命中率、样本数、各联赛命中率、主/平/客混淆矩阵、Brier Score、Log Loss 和置信度分桶校准。不得只展示最好的一天。

## 80% 目标的验收办法
- 每日：展示当天全部预先选定比赛及逐场对照。6 场至少 5 场命中才达到当日 80%（83.3%）；7 场至少 6 场命中（85.7%）；8 场至少 7 场命中（87.5%）。4/6、5/7 或 6/8 均未达到 80%。
- 正式验收不能只依赖单日：需使用严格时间顺序、无赛后数据泄漏的连续独立前瞻样本。至少累计 100 场后，才初步评估是否接近目标；继续扩大样本并按联赛分层。
- 同时检查平局是否被系统性漏判、主客场偏差、强弱队错判、高置信度错误及净胜球 0/1/2/3+ 分布。不能通过把所有平局都排除在候选集外来虚增准确率。
- 与现有 V5.1 冻结基线进行同场对照；任何新参数或模块从新版本（如 V5.2）开始，保留 V5.1 原版和旧预测，不覆盖历史数据。
- 只有当新版本在独立时间留出集上的准确率和概率评分有稳定改善，且没有明显的概率失准，才允许晋级。若证据不足，标记“尚未达标/样本不足”，不宣称达到 80%。

## 每日选场流程
1. 先汇总当日候选赛程并完成球队、开球时间和联赛核验。
2. 核查可用的实力、首发/伤停、关键球员、主客场 xG/xGA、近期表现、战术、天气、裁判、盘口变化、赛程密度、下一场重要性及可信评论员观点。
3. 为每个输入记录来源、采集时间、数据状态（已采集/已核实/已进入模型）。缺失数据明确标注，不得编造。
4. 生成胜/平/负概率并校准。只有达到预先设定的置信度和数据质量条件的比赛进入重点推荐名单；若合格场次不足 6 场，仍可列出候选预测，但必须标记“低置信度/未达选场门槛”，不能把它们包装成高信心推荐。
5. 赛后逐场核实比分，计算命中率与错误原因，并归档到仓库。写入成功必须有 GitHub commit 回执；模型实际运行必须有运行日志或输出证据。

## 禁止事项
- 不承诺每天必然达到 80%，不因单日未达标就事后修改预测。
- 不使用最终首发、赛后 xG、红牌/点球等赛后事件作为赛前输入。
- 不以赔率单独决定胜负。
- 不把回顾性重建当作真正的赛前盲测。
- 不以 6–8 场的小样本结果替代连续独立样本验证。
